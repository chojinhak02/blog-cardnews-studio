# 블로그·카드뉴스 통합 작업실

`index.html`을 브라우저에서 열면 블로그 스튜디오가 시작됩니다. 왼쪽 메뉴 하단의 **카드뉴스 생성기**를 누르면 카드뉴스 작성 화면으로 이동합니다. 카드뉴스 화면의 **블로그 스튜디오** 링크로 돌아올 수 있습니다.

`blog-studio-backup/index.html`은 통합 전 블로그 사이트의 백업입니다. 함께 있는 CSS·JavaScript 파일까지 복사해 독립적으로 열 수 있습니다.

입력 내용과 보관함은 브라우저의 로컬 저장소를 사용합니다. 블로그와 카드뉴스의 저장 기능은 각 화면의 버튼으로 직접 실행합니다.
